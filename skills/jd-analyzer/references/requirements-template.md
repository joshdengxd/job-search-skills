# Job requirements (template for jd-analyzer)

Copy to your project (default path `./preferences.md`), fill in, keep current. jd-analyzer turns each "hard" line into a gate (Eligible | Ineligible | Unverified). Failing any hard gate = never pursued, regardless of fit.

## Hard requirements (gates)
1. Work arrangement: e.g. fully remote (hybrid/office days = Ineligible).
2. Location / work eligibility: where you live, what hiring entities count (e.g. "US Remote" with no mention of your country = Unverified, never Eligible).
3. Minimum base pay: amount + currency (base only; state FX assumption if converting).
4. Employer type: e.g. no outsourcing / staff-aug / consulting; minimum company size.
5. Tooling / policy: e.g. must allow AI coding agents (absent evidence = Unverified).
6. Culture / intensity red flags (label as anecdotal).

## Target roles
Primary / secondary / avoid.

## Candidate facts (paths)
- Master resume: `master-resume.md` (fact bank).
- Career profile / fact corrections: `career-profile.md` (optional).

## Notes
Anything else a recruiter-facing analysis must respect (timelines, deal-breakers).
